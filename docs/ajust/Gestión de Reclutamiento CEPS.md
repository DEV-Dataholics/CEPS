**Reclutamiento en Campo** (Field Recruitment) serves as the foundational entry point for the entire **Sistema CEPS** operational flow, which is designed to streamline vacancy management and the handling of security guards (*guardias de seguridad*) 1\.

### 1\. Automated Data Capture in the Field

* **Recruiter Location Point:** Field recruiters operate from various physical points and select their current location within the system to start a registration 1\.  
* **Document Scanning (CURP):** Scanning candidate documentation—preferably the CURP—automatically extracts and populates baseline applicant information into the system 1\.  
* **Automated Address Filling:** Recruiters can capture applicant addresses either via a location button ("*estoy en mi casa*") or by searching and confirming the address on an integrated map 2\. This auto-fills form fields while allowing recruiters to make manual adjustments when necessary 2\.

### 2\. Instant Database Validation & Blacklist Filter

* **Real-time Database Query:** Upon scanning candidate documents in the field, the system executes a rapid backend query to check if the applicant already exists in the database 3\.  
* **Ineligibility Warning:** If the candidate was previously marked as non-hireable (*no contratable*) by an administrator, the system immediately flags them (e.g., "*candidato sin posibilidad de aplicación*") 3, 4\. This alerts the recruiter on the spot and prevents unnecessary data entry for ineligible applicants 3, 4\.

### 3\. Integration into the Broader Sistema CEPS Architecture

* **Candidate Profile Generation:** The basic information gathered during field recruitment is sufficient to create an initial candidate profile, which is pushed directly to the administrator's candidate management inbox (*bandeja de administración de candidatos*) 5\.  
* **Transition to Evaluation:** Once the administrator reviews and approves the candidate profile, the applicant moves from the field stage to completing digital, tablet-based exams linked to a unique ID/QR code generated during registration 5-7.  
* **Role-Based Access:** In Sistema CEPS, the field recruiter represents one of four dedicated system roles (alongside Candidate, Vacancy Administrator, and General Administrator), each restricted to specific system views and permissions 8\.  
* **Final Deployment:** Once exams are completed and documentation is confirmed, the candidate enters the active pool and becomes available for assignment to client vacancies 4, 9\.
